# Title: Task 2 - ReactTS Links Vault

## Objective
The objective of this task is to assess your understanding of array methods, array manipulation, objects, React’s useState hook, props and also introduce you to browser local storage.

**This is the second official task for React based on Lesson 2.**
 
**Scenario**: You are tasked with building a simple (MVP) of a web application that allows users to keep track of their favorite links. Similar to the bookmark functionality of browsers but one that can be accessed from anywhere, without being limited to the same browser every time. For an MVP, you are asked to use local storage as a proof of concept (extend with actual db to make it more applicable to the real world).

## REQUIREMENTS ##

**Interface**
    1. Create a user-friendly interface that is intuitive and easy to use
    2. The interface should be responsive to different screens
    3. Interface should make use of aesthetically pleasing color combinations
    4. The interface should have a good layout that is easy to navigate
    5. The interface should have relevant inputs to store the following details about the link
       - asdff
       - Title
       - Link (URL)
       - Description
       - Optional tags


**Functionality**
1. Users should be able to the following CRUD (create, read, update, delete) operations on the application:
   - Save new links
   - View saved links
   - Edit/update saved links
   - Delete links
2. Users should be able to search the saved links based on
   - Tags
   - Link
   - Description
   - Title

**Persistence**
1. Make use of localStorage to store the link details
 
**Concepts the task covers**
1. Arrays and array methods
2. Objects and object methods
3. LocalStorage
4. React components
5. Component reusability
6. React hooks: useEffect, useState, etc
7. React props
9. JSON object and its methods
10. Web page responsiveness

**Instructions:**
1. Come up with your own design for the problem statement
2. Create a React application that mimics your design to solve the problem
3. Make use of components wherever applicable
4. In terms of CSS the portal should be as responsive as possible, meaning it should be fully accessible on all platforms, whether desktop, laptop or mobile devices. All this without distorting the inputs you will have on the screen.
5. The main point of data storage will be local storage, which will allow you to add, update and delete from it.
6. Use plain CSS and media queries. Third party CSS libraries are not allowed
7. Host the site when done
